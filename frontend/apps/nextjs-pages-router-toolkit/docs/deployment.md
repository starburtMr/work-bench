# Deployment

Deploy the Next.js application on a platform that supports Pages Router builds, server rendering, environment variables, and static assets. Good options include:

- [Vercel](https://vercel.com/)
- [Netlify](https://www.netlify.com/)
- [AWS Amplify](https://aws.amazon.com/amplify/)
- [Cloudflare Pages](https://pages.cloudflare.com/)

Before deployment, replace the mock API with the target backend or configure the frontend environment values to point at the deployed API.
