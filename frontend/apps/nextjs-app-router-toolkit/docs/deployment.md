# 🌐 Deployment

Deploy the Next.js application on a platform that supports App Router builds, server rendering, environment variables, and static assets. Good options include:

- [Vercel](https://vercel.com/)
- [Netlify](https://www.netlify.com/)
- [AWS Amplify](https://aws.amazon.com/amplify/)
- [Cloudflare Workers](https://workers.cloudflare.com/)
