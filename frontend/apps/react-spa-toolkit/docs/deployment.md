# Deployment

This skeleton builds a static SPA with Vite. Deploy the generated assets over a CDN or static hosting platform, and configure `VITE_APP_API_URL` for the target backend before building.

Good options include:

- [Vercel](https://vercel.com/)
- [Netlify](https://www.netlify.com/)
- [AWS](https://aws.amazon.com/cloudfront/)
- [CloudFlare](https://www.cloudflare.com/en-gb/cdn/)
