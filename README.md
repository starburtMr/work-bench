# Workspace Index

这个工作区是给 Codex 这类编程助手使用的，用来初始化前端和后端项目骨架。

## 使用方式

1. 先确认目标是 `frontend` 还是 `backend`。
2. 再根据目标平台选择对应的技术栈示例。
3. 把选中的模板目录里的骨架复制到目标项目目录。
4. 复制完成后，再按对应项目里的 `README.md`、`AGENTS.md` 和 `docs/` 做适配。

## 目录说明

- `frontend/` - 前端模板集合和前端总索引
- `backend/` - 后端模板集合和后端总索引

## 复制规则

- 前端初始化时，优先使用 `frontend/apps/` 下对应技术栈的示例目录。
- 后端初始化时，优先使用 `backend/apps/` 下对应技术栈的示例目录。
- 实际落地时，把对应示例里的骨架目录复制到目标项目目录，再补环境变量、文档和约束文件。

## 参考入口
