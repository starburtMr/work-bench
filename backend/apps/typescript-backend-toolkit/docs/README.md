# Documentation Index

This folder is a short index for the TypeScript backend toolkit skeleton docs.
The runtime stack is Express + MongoDB/Mongoose + Redis/BullMQ + a plugin system.
Each page is intentionally brief so it is easy to scan and reuse.

## Pages

- `application-overview.md` - what the runtime is and what it ships with
- `project-structure.md` - the runtime folders and their responsibilities
- `project-standards.md` - coding and architecture rules
- `commands.md` - common pnpm, Docker, and CLI commands
- `architecture.md` - the runtime flow, modules, and plugin system
- `magic-router.md` - routing, schemas, and response patterns
- `security.md` - auth, sessions, uploads, and environment rules
- `testing.md` - verification and debugging guidance
- `deployment.md` - local, Docker, and production run notes
- `additional-resources.md` - key files and references
