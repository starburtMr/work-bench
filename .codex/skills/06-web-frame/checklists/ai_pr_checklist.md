# AI PR Checklist

每次让 AI 修改代码后，用此清单检查。

## 修改范围

- [ ] AI 先说明了本次修改目标。
- [ ] AI 先说明了影响文件。
- [ ] AI 没有改无关模块。
- [ ] AI 没有擅自新增依赖。
- [ ] AI 没有擅自更换技术栈或组件库。

## 目录与组件

- [ ] 新文件放在正确目录。
- [ ] 页面文件仍然保持轻薄。
- [ ] 业务逻辑在模块内。
- [ ] API 请求没有散落在组件里。
- [ ] 重复 UI 已复用或抽象。

## 样式

- [ ] 没有新增散落硬编码颜色。
- [ ] 没有新增随机 px 间距。
- [ ] 圆角、阴影、字体来自 Token 或组件库主题。
- [ ] 响应式规则没有被破坏。

## 页面状态

- [ ] loading 状态存在。
- [ ] empty 状态存在。
- [ ] error 状态存在。
- [ ] success 状态存在。
- [ ] unauthorized / forbidden 状态按需存在。

## 质量

- [ ] type-check 通过。
- [ ] lint 通过。
- [ ] build 通过。
- [ ] 关键流程可手动验收。
- [ ] AI 给出了启动与验收方式。
