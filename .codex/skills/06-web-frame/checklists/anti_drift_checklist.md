# ANTI_DRIFT_CHECKLIST.md

用于每次 Vibe Coding 后检查是否跑偏。

## 1. 技术方向

- [ ] 是否擅自换框架？
- [ ] 是否擅自换组件库？
- [ ] 是否擅自新增依赖？
- [ ] 是否破坏框架目录约定？

## 2. 目录

- [ ] 新文件是否放在正确目录？
- [ ] 页面是否只做组合？
- [ ] API 是否放在模块 api 或统一 api 层？
- [ ] 私有组件是否被跨模块偷用？

## 3. 组件

- [ ] 是否复用已有组件？
- [ ] 是否复制粘贴重复 UI？
- [ ] 是否新增组件登记？
- [ ] 是否绕过组件库重复造轮子？

## 4. 样式

- [ ] 是否硬编码颜色？
- [ ] 是否硬编码间距/圆角/阴影？
- [ ] Tailwind 是否大量使用任意值？
- [ ] 组件库覆盖是否集中？

## 5. API 与状态

- [ ] 是否页面内直接请求？
- [ ] 是否错误处理散落？
- [ ] 是否把服务端状态塞进全局 store？
- [ ] 是否处理 loading/empty/error/forbidden？

## 6. 验证

- [ ] 是否给出启动/构建/测试命令？
- [ ] 是否说明影响范围？
- [ ] 是否更新相关文档？
