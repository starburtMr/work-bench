## 6. 请求处理链路

```text
HTTP 请求
→ 路由/Controller/Handler
→ 参数校验
→ 认证与权限占位
→ Service / Use Case
→ Repository / Data Access
→ 统一响应
→ 全局错误处理
→ 请求日志/错误日志
```

## 7. API 响应规范

### 对象成功响应

```json
{
  "success": true,
  "data": {},
  "meta": {
    "requestId": "req_xxx",
    "timestamp": "2026-06-09T12:00:00Z"
  }
}
```

### 列表成功响应

```json
{
  "success": true,
  "data": {
    "items": [],
    "pagination": {
      "page": 1,
      "pageSize": 20,
      "total": 0,
      "totalPages": 0
    }
  },
  "meta": {
    "requestId": "req_xxx",
    "timestamp": "2026-06-09T12:00:00Z"
  }
}
```

### 失败响应

```json
{
  "success": false,
  "error": {
    "type": "https://example.com/problems/example",
    "code": "VALIDATION_ERROR",
    "title": "Bad Request",
    "status": 400,
    "message": "请求参数错误",
    "details": null
  },
  "meta": {
    "requestId": "req_xxx",
    "timestamp": "2026-06-09T12:00:00Z"
  }
}
```

| 系统异常 | 500 | INTERNAL_ERROR |  |

## 9. 业务错误码登记表

| 错误码 | HTTP 状态码 | 用户提示 | 触发场景 | 维护位置 |
|---|---:|---|---|---|
| VALIDATION_ERROR | 400/422 | 请求参数错误 | 参数校验失败 |  |
| AUTH_UNAUTHORIZED | 401 | 未登录或登录已过期 | 缺少/无效 token |  |
| AUTH_FORBIDDEN | 403 | 无权限操作 | 角色或对象权限不足 |  |
| RESOURCE_NOT_FOUND | 404 | 资源不存在 | 查找对象失败 |  |
| INTERNAL_ERROR | 500 | 系统异常 | 未预期错误 |  |

## 10. 参数校验规则

- path/query/body/header/file/webhook payload 均必须后端校验。
- 校验内容包括必填、类型、长度、格式、枚举、数值范围、分页上限、字段白名单。
- 不得仅依赖前端校验。
