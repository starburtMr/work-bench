## 3. 索引规则

- 索引必须服务真实查询。
- 组合索引字段顺序应匹配过滤与排序。
- 唯一业务标识必须用唯一约束或唯一索引保护。
- 高频软删除查询可考虑 `deleted_at` 相关索引。
- PostgreSQL 可考虑 partial index，例如 `WHERE deleted_at IS NULL`。
- 不要给所有字段加索引。
- 大表新增索引要评估锁、耗时、写入影响。

## 4. 验收

- 使用典型 WHERE / ORDER BY / LIMIT 查询测试。
- 检查是否使用预期索引。
- 检查插入/更新成本是否可接受。
