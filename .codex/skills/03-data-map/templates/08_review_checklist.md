# 数据库设计评审清单

## 1. 反幻觉检查

- [ ] 每张表都有业务来源。
- [ ] 没有凭行业模板硬加无来源表。
- [ ] 所有合理推导都标注为“合理推导”。
- [ ] 所有影响结构的不确定点都列入“待确认”。

## 2. 关系检查

- [ ] 一对多外键放在多的一方。
- [ ] 多对多使用中间表。
- [ ] 有业务属性的中间表被建成独立业务表。
- [ ] 外键方向正确。
- [ ] 删除策略明确。
- [ ] 历史快照不依赖当前可变资料。

## 3. 字段检查

- [ ] 字段原子化。
- [ ] 命名统一小写下划线。
- [ ] 主键、时间戳、软删除字段规范。
- [ ] 状态字段枚举化。
- [ ] 金额字段不使用浮点数。
- [ ] 密码只存 hash。
- [ ] 敏感字段有加密/脱敏/最小化策略。

## 4. 范式与反范式

- [ ] 符合 1NF。
- [ ] 符合 2NF。
- [ ] 符合 3NF 或明确说明反范式原因。
- [ ] 冗余字段有同步和一致性策略。

## 5. 约束与索引

- [ ] 唯一业务键有唯一约束。
- [ ] 必填字段 NOT NULL。
- [ ] 外键约束或应用级关系策略明确。
- [ ] 索引来自真实查询场景。
- [ ] 没有盲目给所有字段加索引。

## 6. Migration 与上线

- [ ] 输出可提交 Git 的 Schema/Migration 文件。
- [ ] 生产不依赖自动同步。
- [ ] 破坏性变更有迁移计划。
- [ ] 有数据回填方案。
- [ ] 有验收 SQL / 测试数据。
- [ ] 有备份和回滚/前滚方案。
