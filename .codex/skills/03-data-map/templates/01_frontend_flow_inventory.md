## 前端字段还原规则

前端展示字段不一定是数据库字段。必须判断：

- 展示字段是否由多个字段拼接？例如 `contact = name + phone`。
- 展示字段是否是聚合值？例如 `order_count`、`comment_count`。
- 展示字段是否是权限过滤结果？例如“可操作按钮”。
- 展示字段是否是临时 UI 状态？例如 `isOpen`、`selectedRows`。
- 展示字段是否是后端计算值？例如 `display_status`、`remaining_time`。

输出时把这些字段标注为：数据库原子字段 / 计算字段 / 聚合字段 / UI 临时字段 / 权限派生字段。
