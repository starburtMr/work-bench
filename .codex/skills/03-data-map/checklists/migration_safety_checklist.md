# Migration 安全清单

## 上线前

- [ ] Migration 文件已提交 Git。
- [ ] 生成的 SQL 已审查。
- [ ] staging 已执行。
- [ ] 已备份生产数据。
- [ ] 已确认执行时间窗口。
- [ ] 已准备回滚或前滚方案。
- [ ] 数据回填脚本可重复执行。
- [ ] 破坏性变更已拆分为 expand-contract。

## 变更类型

- [ ] 新增表。
- [ ] 新增 nullable 字段。
- [ ] 新增 not null 字段。
- [ ] 改字段类型。
- [ ] 重命名字段。
- [ ] 删除字段。
- [ ] 新增唯一约束。
- [ ] 新增外键。
- [ ] 新增索引。
- [ ] 数据回填。

## 风险处理

| 风险 | 处理方式 |
|---|---|
| 长事务 | 分批、短事务 |
| 锁表 | 在线 DDL / 并发索引 / 低峰执行 |
| 数据丢失 | 备份、影子字段、双写 |
| 应用不兼容 | 先发布兼容代码 |
| 回填失败 | 幂等脚本、断点续跑 |
