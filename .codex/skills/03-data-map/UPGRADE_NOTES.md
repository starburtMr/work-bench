# v3 升级说明

这次升级针对“原 Skill 还不够强”的问题，重点补了四类能力。

## 1. 从理念升级为工程流程

旧版主要强调“不要凭空造表”。新版把流程拆成可执行链路：

`业务流程证据 → 业务对象 → 关系矩阵 → 生命周期 → 数据库选型 → 字段规范 → 约束索引 → Schema/Migration → 迁移安全 → 验收标准`

## 2. 增加官方框架适配

新增适配器：

- PostgreSQL / MySQL / SQLite / Redis。
- Prisma。
- Django。
- Laravel。
- Rails。
- TypeORM。
- Drizzle。
- SQLAlchemy / Alembic。
- EF Core。
- 前端证据提取。

每个适配器都写明：适用场景、输出文件、字段规范、生产注意事项、禁止事项。

## 3. 增加生产迁移安全

新版不只会“设计表”，还会审查上线风险：

- nullable 改 not null。
- 删除字段/表。
- 修改字段类型。
- 新增唯一约束。
- 新增外键。
- 大表新增索引。
- 数据回填。

并加入 expand-contract 发布模式。

## 4. 增加安全与合规硬规则

新版把以下内容写成硬规则：

- 密码只存 `password_hash`。
- 金额不用浮点数。
- 敏感数据最小化存储。
- 日志不记录密码、token、密钥、连接串、银行卡等。
- 核心业务数据默认软删除。
- 历史订单使用快照。

## 5. 增加模板、Prompt 和示例

新增：

- 需求收集模板。
- 前端流程证据模板。
- 业务对象清单模板。
- 关系矩阵模板。
- 单表规格模板。
- 查询与索引计划模板。
- 框架输出契约。
- 安全生命周期清单。
- 迁移实施计划。
- 电商 / SaaS / 预约系统示例。
