## 新项目骨架提示词

```md
请使用 Frontend Skeleton Architect Skill。
模式：0 到 1 新项目骨架。
在没有问清目标平台、项目类型、页面地图、设计风格、技术栈、组件库、接口状态之前，不要直接生成页面代码。
请先输出：
1. 澄清问题；
2. 技术选型建议；
3. 前端蓝图目录；
4. 骨架阶段实施计划；
5. 验收标准。
```
