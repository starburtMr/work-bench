# ACCEPTANCE_CHECKLIST.md

## 1. 骨架阶段验收

- [ ] 项目使用明确的官方脚手架或成熟框架创建。
- [ ] `package.json` 中存在 dev/build/typecheck/lint/format/test/test:e2e 等脚本或明确说明暂缓原因。
- [ ] 项目可以启动本地开发服务。
- [ ] 至少一个首页 / 示例页面可访问。
- [ ] 路由策略明确。
- [ ] UI 组件库已接入并有示例组件。
- [ ] 全局 Design Token 已定义。
- [ ] 样式没有散落硬编码主色、圆角、阴影。
- [ ] 目录结构符合 `PROJECT_STRUCTURE.md`。
- [ ] 至少有 `ui`、`layout`、`feedback` 组件目录。
- [ ] `LoadingState`、`EmptyState`、`ErrorState` 至少存在或被明确规划。
- [ ] API request client 已建立。
- [ ] API 契约已定义。
- [ ] Mock 策略已定义或接入。
- [ ] AI 后续约束文件存在。

## 2. 页面阶段验收

- [ ] 新页面已加入页面地图。
- [ ] 新路由已更新路由表。
- [ ] 页面有 loading / empty / error / forbidden / success 状态。
- [ ] 页面复用布局和通用组件。
- [ ] 页面没有直接请求 API。
- [ ] 页面没有硬编码主题样式。
- [ ] 移动端 / 响应式行为符合预期。

## 3. API 阶段验收

- [ ] 新接口已写入 API 契约。
- [ ] DTO 类型已定义。
- [ ] Mock handler 已更新。
- [ ] 错误结构统一。
- [ ] 鉴权和权限错误处理清晰。
- [ ] 页面状态映射正确。

## 4. 既有项目优化验收

- [ ] 先新增或更新文档护栏，再做代码改动。
- [ ] 每次只迁移一个明确范围。
- [ ] 构建未被破坏。
- [ ] 旧页面视觉没有意外大变。
- [ ] 重复组件减少。
- [ ] 硬编码样式减少。
- [ ] API 请求更集中。
- [ ] 后续 AI 任务可引用规范文件。
