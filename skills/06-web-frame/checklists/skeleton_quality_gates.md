# 前端骨架质量门禁

## 1. 决策门禁

- [ ] 已判断模式：新项目 / 既有项目。
- [ ] 已确认目标平台。
- [ ] 已确认产品类型。
- [ ] 已确认第一阶段页面。
- [ ] 已确认设计风格或写明默认假设。
- [ ] 已确认技术栈或写明推荐理由。
- [ ] 已确认组件库。
- [ ] 已确认接口状态。

## 2. 架构门禁

- [ ] 有前端蓝图。
- [ ] 有目录结构规范。
- [ ] 有组件规范。
- [ ] 有 Design Token。
- [ ] 有 API 契约。
- [ ] 有状态管理策略。
- [ ] 有测试策略。
- [ ] 有 AI 护栏。

## 3. 代码门禁

- [ ] 不在页面中直接请求接口。
- [ ] 不重复实现组件库已有基础组件。
- [ ] 不硬编码主色、圆角、阴影、z-index。
- [ ] 不新增无说明依赖。
- [ ] 不把所有状态塞进全局 store。
- [ ] 页面状态覆盖 loading / empty / error / forbidden。

## 4. 验收门禁

- [ ] dev 可启动。
- [ ] build 可执行。
- [ ] typecheck 可执行。
- [ ] lint 可执行。
- [ ] format 可执行。
- [ ] test 或测试入口存在。
- [ ] test:e2e 或冒烟测试入口存在。
- [ ] docs 已更新。
