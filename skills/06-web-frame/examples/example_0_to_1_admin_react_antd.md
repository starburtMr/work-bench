# 示例：0 到 1 管理后台 React + Ant Design

```md
请启用 Frontend Skeleton Architect Vibe Coding Skill。

模式：新项目从 0 到 1。

设计风格：企业级后台，高信息密度，浅色，简洁商务。

请不要直接写所有页面。先输出前端骨架蓝图、目录结构、组件清单、Design Token、API 契约、AI Guardrails 和第一阶段验收标准。
```
