# 示例：从 0 到 1 搭前端骨架

请启用 frontend-skeleton-vibe-coding Skill。

我想做一个 B 端客户管理后台，第一阶段需要：登录页、首页仪表盘、客户列表、客户详情、客户创建/编辑表单。用户角色有管理员和销售。

我没有强技术偏好，希望你给出成熟默认方案。设计风格要简洁、商务、高信息密度，不要花哨。后端接口暂时没有，先用 Mock，但要把 API 契约写清楚。

要求：
1. 先输出前端决策表，不要直接写页面。
2. 明确技术栈、组件库、目录结构、组件规范、Design Token、API 契约。
3. 输出 AI_GUARDRAILS，防止后续 Vibe Coding 写乱。
4. 第一阶段只搭骨架和首批示例页面，不要横推全部业务。
