# 产品立项问题库

## 1. 破题问题

1. 这个产品一句话是什么？
2. 你为什么想做它？
3. 这个想法来自你的真实经历、用户反馈，还是市场观察？
4. 如果只能解决一个问题，它是什么？
5. 如果三个月后这个项目失败，最可能的原因是什么？

## 2. 用户问题

1. 第一批用户是谁？
2. 他们现在如何解决这个问题？
3. 他们有没有强烈动机换工具？
4. 他们愿意付出什么成本？注册、上传数据、学习、迁移、付费？
5. 哪些用户先不服务？

## 3. JTBD 问题

1. 用户在什么情境下会想起这个产品？
2. 最近一次发生这个问题是什么时候？
3. 用户当时在做什么？
4. 当前流程哪里卡住？
5. 用户想完成什么进步？

## 4. MVP 问题

1. V1 只验证一个假设，它是什么？
2. 没有哪个功能，V1 就完全不成立？
3. 哪些功能可以人工绕路？
4. 哪些功能只是锦上添花？
5. 哪些功能必须明确不做？
6. 哪些 V2/V3 功能正在伪装成 V1 必需？

## 5. 用户路径问题

1. 用户第一次进入看到什么？
2. 用户第一步必须做什么？
3. 用户输入什么？
4. 系统返回什么？
5. 用户如何知道自己成功了？
6. 失败时如何补救？

## 6. 数据对象问题

1. 核心对象是什么？
2. 谁创建它？
3. 谁能查看、修改、删除？
4. 它和其他对象有什么关系？
5. 哪些数据敏感？
6. 哪些数据 V1 不需要保存？

## 7. 风险问题

1. 用户真的要吗？
2. 用户会用吗？
3. 技术能做吗？
4. 商业/运营/合规可持续吗？
5. 最大兔子洞是什么？
6. 最容易导致重写的决策是什么？

## 8. 版本路线图问题

1. 哪些功能只属于 V1？
2. 哪些功能应该放到 V1.1？
3. 哪些功能必须等 V1 反馈后才决定是否进入 V2？
4. 哪些功能属于 V3 的规模化问题？
5. 哪些功能属于 V4+ 长期平台化幻想，目前只能放 Parking Lot？
6. 哪些未来需求会影响现在的底层架构，必须提前作为约束预留？
