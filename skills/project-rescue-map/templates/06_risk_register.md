# Rescue Risk Register

## 风险评分字段

- `Impact`：1-5，影响范围。
- `Likelihood`：1-5，发生概率。
- `Reversibility`：1-5，越不可逆分越高。
- `Evidence Gap`：1-5，缺证越多分越高。
- `Blast Radius`：1-5，影响模块/用户/数据范围。
- `Score`：五项相加。

填写规则：

- `管理大类` 只能填：范围 / 架构 / 骨架 / 交付 / 验收。
- `关联阶段` 记录证据来自哪个 01-10 执行阶段，例如 `03 数据`、`04 API`、`10 验收`。
- 五大类只用于聚合摘要，不得在风险登记表中为聚合摘要单独创造新证据。

## 风险处置动作

| 动作 | 含义 |
|---|---|
| `Avoid` | 暂停或取消相关范围 |
| `Reduce` | 通过补真源、测试、隔离、重构计划降低风险 |
| `Transfer` | 转给负责人/供应商/平台约束处理 |
| `Accept with waiver` | 明确豁免期限和复查条件后暂时接受 |
| `Monitor` | 观察并定义触发信号 |
