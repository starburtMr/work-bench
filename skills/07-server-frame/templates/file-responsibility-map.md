## 3. 禁止依赖规则

- 路由/Controller/Handler 不得直接依赖数据库查询细节。
- Repository/Data Access 不得依赖 HTTP 响应对象。
- Config 不得依赖具体业务模块。
- Logger 不得依赖具体业务模块。
- Utils 不得承载业务规则。
- Error codes 不得在各业务文件中随手新增，必须集中登记。
