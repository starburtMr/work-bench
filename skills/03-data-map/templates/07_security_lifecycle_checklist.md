# 安全与生命周期设计清单

## 1. 密码与认证

- [ ] 不存明文密码。
- [ ] 字段名使用 `password_hash`。
- [ ] 使用 Argon2id / bcrypt / scrypt / PBKDF2 等慢哈希。
- [ ] token、session、refresh token 不直接明文长期存储。
- [ ] 登录日志不记录密码、完整 token。

## 2. 敏感数据

| 数据 | 是否必须存 | 存储方式 | 脱敏方式 | 加密方式 | 访问控制 | 保留期限 |
|---|---|---|---|---|---|---|

- [ ] 只存业务必需数据。
- [ ] 身份证、银行卡、健康数据等高敏数据不默认存。
- [ ] 需要明文展示的数据使用加密或专用安全存储。
- [ ] 日志中敏感字段脱敏、哈希或不记录。

## 3. 财务与支付

- [ ] 金额不用 float/double。
- [ ] 明确币种。
- [ ] 明确精度和舍入规则。
- [ ] 支付单、退款单、回调日志分离。
- [ ] 幂等键 / 第三方流水号唯一。

## 4. 删除与保留

- [ ] 核心业务表默认 `deleted_at` 软删除。
- [ ] 合规删除有单独策略。
- [ ] 审计日志不可随意物理删除。
- [ ] 可重建缓存可以物理删除。

## 5. 审计

- [ ] 关键操作记录 `actor_id`。
- [ ] 记录操作对象、操作类型、结果、时间。
- [ ] 记录请求追踪 ID / interaction ID。
- [ ] 不记录秘密、密钥、完整 token、数据库连接串。
