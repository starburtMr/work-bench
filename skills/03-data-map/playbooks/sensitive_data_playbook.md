# 敏感数据处理手册

## 1. 数据分级

| 等级 | 示例 | 处理建议 |
|---|---|---|
| 低 | 普通展示名、公开内容 | 正常存储 |
| 中 | 邮箱、手机号、地址 | 最小化、访问控制、必要时脱敏 |
| 高 | 身份证、银行卡、健康信息 | 尽量不存；必须存时加密、隔离、审计 |
| 秘密 | 密码、token、密钥、连接串 | 不明文存；token/密钥进入专用密钥系统或哈希引用 |

## 2. 密码

- 字段名：`password_hash`。
- 不存明文。
- 不用 SHA-256 直接哈希密码。
- 使用 Argon2id / bcrypt / scrypt / PBKDF2。
- 不在日志中记录密码。

## 3. Token

- Refresh token 不建议明文长期存储。
- 可存 token hash + 过期时间 + 撤销状态。
- 访问 token 不应进入业务日志。

## 4. 支付信息

- 不直接存银行卡完整号。
- 使用支付平台 token / customer id。
- 支付回调 payload 要脱敏或只存 hash/摘要。

## 5. 日志

日志不要记录：

- 密码。
- access token / refresh token。
- API key。
- 数据库连接串。
- 加密密钥。
- 银行卡完整信息。
- 高敏 PII 原文。
