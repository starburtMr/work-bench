# Schema 审查清单

## 阻塞级问题

- [ ] 明文密码。
- [ ] 金额使用 float/double。
- [ ] 生产建议使用自动同步或直接 push。
- [ ] 多对多塞进字符串/JSON 且无充分理由。
- [ ] 订单/支付/审计等核心历史数据默认物理删除。
- [ ] 删除字段/表但无迁移和数据保护计划。
- [ ] 缺少核心唯一约束导致重复订单/重复支付/重复账号。

## 高风险问题

- [ ] 外键方向错误。
- [ ] 历史快照缺失。
- [ ] 敏感数据无最小化、脱敏、加密策略。
- [ ] 状态字段无枚举和流转说明。
- [ ] 新增 not null 字段无默认值和回填计划。
- [ ] 新增唯一约束前未清理重复数据。
- [ ] 大表索引未评估锁和耗时。

## 中风险问题

- [ ] 字段命名不统一。
- [ ] 索引缺少查询依据。
- [ ] 软删除字段无查询策略。
- [ ] `metadata` / JSON 字段承载了核心结构化关系。
- [ ] 冗余字段无同步策略。

## 建议级问题

- [ ] 缺少表/字段注释。
- [ ] 缺少测试数据。
- [ ] 缺少 ERD。
- [ ] 缺少待确认问题。
